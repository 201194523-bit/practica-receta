Pregunta 2

```

¿Cuál es la etiqueta correcta para mostrar un encabezado principal?

  • <head>
  • <h1>
  • <header>
  • <title>

Mi respuesta: <title>

Respuesta correcta: <h1>

Me equivoqué porque confundí la etiqueta que define el título principal de una página con la estructura del encabezado. Aunque los títulos se representan con etiquetas como <h1>, seleccioné una opción diferente por asociarla incorrectamente con el concepto de título.

```

Pregunta 4

```

¿Cuál de las siguientes etiquetas es semántica?

  • <div>
  • <span>
  • <section>
  • <font>

Mi respuesta: <div>

Respuesta correcta: <section>

Me equivoqué porque <div> es una etiqueta genérica sin significado semántico. En cambio, <section> describe una sección del contenido y aporta significado estructural al documento.

```

Pregunta 9

```

¿Qué propiedad controla el espacio interno entre el contenido y el borde?

  • margin
  • border
  • spacing
  • padding

Mi respuesta: margin

Respuesta correcta: padding

Me equivoqué porque margin controla el espacio exterior de un elemento. La propiedad padding controla el espacio interno entre el contenido y el borde.

```
